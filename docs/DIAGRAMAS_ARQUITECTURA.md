## Diagrama de Flujo - Creación y Validación de Reseña

```
┌─────────┐
│ Usuario │
└────┬────┘
     │
     │ 1. Escribe reseña con MAYÚSCULAS
     ▼
┌────────────────┐
│   Frontend     │
│  (React App)   │
└────┬───────────┘
     │
     │ 2. POST /api/reviews
     │    { rating, comment, movieId }
     ▼
┌────────────────┐
│    Backend     │
│  (Express API) │
└────┬───────────┘
     │
     │ 3. Validar datos
     │ 4. Crear reseña (validated: false)
     ▼
┌────────────────┐
│   Database     │
│  (PostgreSQL)  │
└────┬───────────┘
     │
     │ 5. Reseña guardada
     ▼
┌────────────────┐
│   Frontend     │
│ (Muestra reseña│
│  no validada)  │
└────────────────┘
     │
     │ ... Esperar 5 minutos ...
     │
     ▼
┌────────────────┐
│ Batch Service  │
│  (Cron Job)    │
└────┬───────────┘
     │
     │ 6. Buscar reseñas no validadas
     ▼
┌────────────────┐
│   Database     │
│  SELECT WHERE  │
│ validated=false│
└────┬───────────┘
     │
     │ 7. Retorna reseñas
     ▼
┌────────────────┐
│ Batch Service  │
└────┬───────────┘
     │
     │ 8. Para cada reseña:
     │
     ├─► 8a. Crear archivo de texto
     │    review-{id}-{timestamp}.txt
     │
     ├─► 8b. Subir a Azure Blob Storage
     │    ▼
     │  ┌────────────────┐
     │  │ Azure Blob     │
     │  │   Storage      │
     │  └────┬───────────┘
     │       │
     │       │ 8c. Retorna URL del blob
     │       ▼
     │  ┌────────────────┐
     │  │ Batch Service  │
     │  └────┬───────────┘
     │       │
     ├─► 8d. Convertir MAYÚSCULAS → minúsculas
     │
     └─► 8e. Actualizar reseña
          ▼
     ┌────────────────┐
     │   Database     │
     │  UPDATE SET    │
     │ validated=true │
     │ blobPath=URL   │
     │ comment=lower  │
     └────┬───────────┘
          │
          │ 9. Reseña actualizada
          ▼
     ┌────────────────┐
     │   Frontend     │
     │ (Usuario recarga│
     │  ve reseña     │
     │  validada)     │
     └────────────────┘
```

## Leyenda

- ✓ = Permitido
- ✗ = Denegado
- → = Flujo de datos
- ▼ = Dirección del flujo
- 🔒 = Componente privado (sin acceso público)
- 🌐 = Componente público (acceso desde internet)
